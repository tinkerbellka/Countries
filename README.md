Countries explorer (REST Countries) - со списком всех стран мира и данными по каждой стране (название,столица,регион, население).
В приложении используется база данных Room "CountriesDatabase" с одной таблицей "favourites":
- code: String — первичный ключ, трёхбуквенный код страны
- Каждая строка таблицы — одна страна, добавленная в избранное

Сценарий использования:
- На экране списка стран пользователь нажимает на звёздочку рядом со страной
- При нажатии код страны сохраняется в таблицу "favourites" в Room
- Экран Избранного загружает из Room все сохранённые коды и по ним запрашивает детали стран через API
- При повторном нажатии на звёздочку запись из таблицы "favourites" удаляется.
После перезапуска приложения все сохраненные в "favoutites" страны благополучно отображаются.
