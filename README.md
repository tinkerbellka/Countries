# Countries Explorer — финальный проект

Демьянова Алёна Владиславовна, Б9123-09.03.03, пикд2

Приложение для просмотра стран (REST Countries) с личным слоем данных поверх API: профили, избранное, заметки, коллекции, история просмотров и офлайн-кэш.

## Что добавлено в финальной работе

- Нижняя навигация: список стран, коллекции, история, настройки.
- Локальные профили (без сервера): имя, опциональный PIN при входе, раздельные данные; опция «показывать мои коллекции другим» — чужие коллекции во вкладке «Общие».
- Offline-first: кэш списка стран в Room с TTL из настроек; при ошибке сети UI читает кэш и показывает баннер.
- WorkManager: периодическое обновление кэша и предзагрузка избранного.
- Личные заметки к странам (влияют на фильтр «С заметками» на списке).
- Пользовательские коллекции стран (связь коллекция ↔ страна в Room).
- История недавно просмотренных стран.
- Расширенные настройки в DataStore: тема, TTL кэша, синхронизация только по Wi‑Fi, сортировка.

## Новые пользовательские данные (Room)

| Сущность | Назначение |
|----------|------------|
| `user_profiles` | Профили: имя, PIN (хэш), флаг публичных коллекций |
| `favourites` | Избранное (привязано к профилю, `addedAt`) |
| `cached_countries` | Кэш ответов API для офлайна |
| `view_history` | История просмотров |
| `country_notes` | Заметки к странам |
| `collections` + `collection_countries` | Коллекции и состав |

В DataStore хранятся только настройки: активный профиль, тема, TTL, флаги фоновой синхронизации, сортировка.

## Новые сценарии

1. **Офлайн-просмотр списка** — при отсутствии сети список берётся из кэша; WorkManager обновляет кэш в фоне; TTL задаётся в настройках.
2. **Профили** — создание с PIN, вход при переключении, приватность коллекций для других профилей на устройстве.
3. **Коллекции** — вкладки «Мои» / «Общие», карточки со счётчиком стран; чужие коллекции только для просмотра.
4. **Заметки и история** — заметка на деталке страны; автоматическая запись в историю; экран «История» с переходом на детали.

## Offline-first

- Источник для списка: сначала сеть, при ошибке — Room-кэш (`cached_countries`).
- Избранное и коллекции всегда локальны (Room).
- Политика свежести: `OfflineSyncPolicy.isCacheFresh` + `cacheTtlHours` из DataStore.
- UI показывает баннер при показе данных из кэша.

## Фоновая обработка (WorkManager)

- `CacheRefreshWorker` — раз в 12 ч обновляет полный список в кэш (при наличии сети по Constraints).
- `FavouritesPreloadWorker` — раз в 6 ч подгружает детали избранных стран и обновляет кэш.
- Расписание пересоздаётся при смене опции «только Wi‑Fi» в настройках.

## Тесты

**Юнит-тесты:**
- `OfflineSyncPolicyTest` — TTL и ключи кэша
- `CountriesRepositoryTest` — кэш при ошибке сети, избранное по профилю
- `PersonalDataRepositoryTest` — история, заметки, коллекции
- `CountriesViewModelTest` — список, debounce, фильтр по заметкам, офлайн-баннер
- `CountryDetailViewModelTest` — загрузка и retry

**Интеграционные (androidTest):**
- `RepositoryRoomIntegrationTest` — Room: избранное, история, кэш

Запуск юнит-тестов: `./gradlew testDebugUnitTest`
